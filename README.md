# Hospital Stay Prediction

This project uses Machine Learning to predict a patient's hospital stay category based on demographic, clinical, and admission-related features. The goal is to support data-driven decision-making and improve hospital resource management.

## Key Features

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Feature Engineering & Encoding
* Machine Learning Model Building
* Model Comparison & Evaluation
* Hospital Stay Prediction

## Technologies Used

* Python
* Pandas & NumPy
* Matplotlib & Seaborn
* Scikit-learn
* Jupyter Notebook

## Models Used

* Logistic Regression
* Random Forest
* Gradient Boosting
* XGBoost
* CatBoost

## Result

The machine learning models were evaluated using accuracy and other classification metrics to identify the best-performing model for hospital stay prediction.
